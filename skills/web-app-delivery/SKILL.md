# 웹 서비스 개발 — 필요한 경우에만 읽는 선택형 Skill

실제 과제 README·제공 코드·운영 정책이 최우선입니다. 이 자료는 Clone만으로 자동 등록되지 않습니다.

1. **탐색:** 필수 사용자 행동, 입력·데이터 스키마·출력 경로·기존 프레임워크와 API를 확인합니다. 업무 정책은 임의로 만들지 않습니다.
2. **설계:** 실제 사용자 입력 → 서버 검증 → 계산/저장 → API 응답 → 화면 표시까지 연결되는 가장 작은 기능 하나를 우선 선택합니다.
3. **구현:** 하드코딩 결과·버튼만 있는 데모를 완료로 간주하지 않습니다. 기존 코드와 실행법을 보존하며 작은 단계로 구현합니다.
4. **검증:** 실제 명령·기대값·관찰값을 구분합니다. 필요한 경우에만 web_project_audit.py와 web_api_check.py, 기존 테스트를 사용합니다.
5. **수동 UI:** 제공된 미리보기에서 본인이 실제 입력·수정·삭제·새로고침·모바일·오류 상태를 확인할 절차를 제공합니다. 관찰 전에는 “미검증”으로 표기합니다.
6. **오류 해결:** 실패 재현 → 첫 원인 추적 → 최소 수정 → 같은 테스트 실행 → 정상 동작 재확인.
7. **설명:** 사용자가 본인의 말로 무엇을·왜·어떻게·실제 검증·한계를 설명할 수 있도록 작업 근거를 간결히 남깁니다.

다른 프로젝트에 이 Skill을 강제 적용하거나, 참고 키트 전체를 제출물로 복사하지 않습니다. 권한·보안 제한·외부 전송 규칙이 우선입니다.
